藏书阁的技术选型

为什么不用 Hexo / Hugo / WordPress？

  • 无框架：纯 HTML + CSS + 原生 JS，不依赖任何构建工具
  • JSON 驱动：所有文章、游戏、工具数据集中在 JSON 文件中，改数据即改内容
  • GitHub Pages 部署：零成本、版本可控
  • 深色 / 浅色主题：CSS 变量 + localStorage 持久化，首屏防闪烁

简单来说：能用 JSON 解决的事，就不写框架。这也是藏书阁名字的由来 —— 像整理书架一样整理数据。
