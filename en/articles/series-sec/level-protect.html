Classified Protection Workflow

Classified Protection Compliance Updated 2022-09-23 · Sect Master

藏
Complete cybersecurity classified protection assessment workflow: Define Objectives → Information Gathering → Vulnerability Detection → Vulnerability Validation → Information Analysis → Obtain Requirements → Information Organization → Generate Report

Hold a Project Kickoff Meeting to Define Objectives and Information

  1. Define the scope of the current testing target: IPs, domains, internal/external networks
  2. Define rules: depth of penetration allowed, attack timeframe, permitted attack methods
  3. Define requirements: web application vulnerabilities / business logic vulnerabilities / personnel management and access control vulnerabilities
  4. Define attack approach: active scanning / open-source intelligence gathering

Information Gathering

  1. Basic information: IPs, business architecture, domains, ports
  2. Version information of various system dependencies
  3. Application information: involved services, application logic

Vulnerability Exploration

Use scanners combined with vulnerability database lookups for exploitation

Vulnerability Validation

  1. Automated validation: verify through tools
  2. Manual validation
  3. Brute force

Information Analysis

Prepare for the next phase of penetration

PS: Precise targeting, bypass mechanisms, exploit code

Obtain Requirements

Launch attacks, exfiltrate databases, establish persistence (backdoors), clear traces

Information Organization

Organize tools used during penetration, collected result information, and vulnerability information

Generate Report

  1. Document vulnerability existence information
  2. Explain the principles behind vulnerabilities
  3. Describe exploitation methods
  4. Provide remediation recommendations
