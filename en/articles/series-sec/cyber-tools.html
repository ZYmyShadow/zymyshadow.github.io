Network Security Tools

Toolkit Penetration Testing Updated 2022-09-15 · Sect Master

藏
This article organizes dozens of classic network security tools by their functional roles and use cases, covering vulnerability scanning, sniffing, penetration testing, password cracking, and more.

Vulnerability Scanners

  • Nessus — The best free network vulnerability scanner, runs on nearly all UNIX platforms, with over 11,000 free plugins
  • OpenVAS — Open-source fork of Nessus, a powerful vulnerability scanner
  • GFI LANguard — Commercial network security scanner for Windows, discovers running computers and collects OS version and application information
  • Retina — Commercial vulnerability assessment scanner by eEye
  • SAINT — Commercial vulnerability assessment tool, similar to Nessus, ISS Internet Scanner, and Retina
  • QualysGuard — Web-based vulnerability scanner with over 5,000 individual vulnerability checks
  • Acunetix WVS — Commercial web vulnerability scanner that automatically checks for SQL injection, cross-site scripting, and other vulnerabilities
  • Nikto — Very comprehensive web scanner with over 3,200 potentially dangerous files/CGIs
  • WebInspect — Powerful web application scanner that helps identify known and unknown web-layer vulnerabilities

Network Sniffing and Analysis

  • Wireshark — Excellent open-source network protocol analyzer for Unix and Windows, capable of real-time network traffic inspection
  • Tcpdump — The most classic network monitoring and data capture sniffer, very few vulnerabilities, minimal system resource consumption
  • Kismet — A powerful wireless sniffer, command-line-based 802.11 Layer 2 wireless network detector
  • NetStumbler — Free Windows 802.11 sniffer, widely known tool for finding open wireless access points
  • Ntop — Network traffic monitor that displays network usage in a manner similar to a process manager

Penetration Testing Frameworks

  • Metasploit Framework — Powerful open-source platform for developing, testing, and using exploit code, includes hundreds of built-in exploits
  • Core Impact — Fully automated comprehensive intrusion detection tool with a powerful, regularly updated professional vulnerability database
  • Canvas — Vulnerability detection tool by Aitel's ImmunitySec, includes over 150 exploits

Password Cracking Tools

  • John the Ripper — The fastest password cracker, currently supports many major Unix, DOS, Win32, BeOS, and OpenVMS platforms
  • Cain and Abel — The best password recovery tool on Windows, can find passwords by sniffing the network
  • THC Hydra — The fastest network authentication cracker supporting multiple services, can perform fast dictionary-based cracking on over 30 ports simultaneously
  • RainbowCrack — Highly innovative password hash cracker using large-scale time-memory tradeoff techniques
  • Aircrack — The fastest WEP/WPA cracking tool, a suite of tools for cracking 802.11a/b/g WEP and WPA

Port Scanning and Host Discovery

  • Nmap — Open-source tool for network exploration and security auditing, supports host discovery, port scanning, service/version detection, and OS detection
  • Masscan — The fastest internet port scanner, can scan the entire internet in 6 minutes
  • Angry IP Scanner — A very fast Windows IP scanner and port scanner
  • Superscan — Port scanner, ping tool, and resolver that runs only on Windows

Firewalls and IDS/IPS

  • Netfilter — The latest Linux kernel packet filter/firewall, integrated with userspace IP table tools
  • OpenBSD PF — OpenBSD packet filter, the most popular firewall tool among OpenBSD users
  • Snort — A widely popular open-source IDS (Intrusion Detection System) tool, excels at traffic analysis and IP packet logging
  • OSSEC HIDS — An open-source host-based intrusion detection system with key features including log analysis, integrity checking, and rootkit detection

Reverse Engineering and Debugging

  • IDA Pro — Windows/Linux disassembler and debugger, the de facto standard tool for malware and vulnerability research analysis of binary packages
  • OllyDbg — Assembly-level Windows debugger, very useful for analyzing binary code directly when source code is unavailable
  • radare2 — Portable reverse engineering framework

Encryption and Anonymity

  • GnuPG / PGP — Advanced encryption for files and communications; GnuPG is a well-regarded open-source application compliant with the PGP standard
  • Tor — Anonymous network communication system with features for anonymous web browsing and publishing, instant messaging, IRC, SSH, and more
  • OpenSSL — The best SSL/TLS encryption library; a robust, full-featured open-source cryptographic toolkit comparable to commercial alternatives
  • TrueCrypt — Open-source disk encryption software for Windows and Linux; users can encrypt entire file systems

Other Useful Tools

  • Netcat — The "Swiss Army knife" of networking, can read and write data over TCP or UDP network connections
  • Hping2 — A network probing tool, a supercharged variant of ping that can send custom ICMP, UDP, and TCP packets
  • Sysinternals — A powerful and comprehensive Windows tool suite, including ProcessExplorer, PsTools, Autoruns, and more
  • VMware — Multi-platform virtualization software that allows running one system inside another; very useful for security professionals testing code and exploits across multiple platforms
  • BackTrack — An innovative Live CD Linux distribution platform, known for its vast collection of security and defense tools and rich development environment
  • Perl / Python / Ruby — Simple, versatile scripting languages; common security problems can be solved with tools found online, but with scripting languages you can write your own
