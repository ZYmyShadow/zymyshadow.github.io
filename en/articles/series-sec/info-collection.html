4. Kali Environment (Authorization Required for Penetration Testing)

  • Log in as root user
  • dnsenum
Parameters:
-f can specify a file (/usr/share/dnsenum/dns.txt)
--dnsserver 114.114.114.114    Returns domain, records, A/NS/MX records, Bind version, zone transfer
Dictionary brute force: -f /usr/share/dnsenum/dns.txt
Forward lookup: dig / nslookup
Reverse lookup:

DNS is the primary source of server information exposure

  • Collect DNS domain information
  • Discover hosts with open ports
  • Discover subdomains and open ports
  • DNS domain registration information
  • DNS server zone transfer

Practical Example

dnsenum qq.com      Subdomain information for the domain
whois qq.com        Domain registration information
nslookup qq.com     Display DNS information
nslookup interactive    server shows local DNS
dig @DNSIP (resolve via specified DNS) qq.com    Collect DNS records
dig +noall (show nothing) +answer (show only returned info) -x (reverse lookup) DNSIP    Reverse lookup
dig +noall +answer txt (specify type) chaos (query) VERSION.BIND (version number) @ns2.baidu.com.
dig +trace (trace) www.baidu.com
