Nmap Official Help

Usage: nmap [Scan Type(s)] [Options] {target specification}
TARGET SPECIFICATION:
  Can pass hostnames, IP addresses, networks, etc.
  Ex: scanme.nmap.org, microsoft.com/24, 192.168.0.1; 10.0-255.0-255.1-254
  -iL <inputfilename>: Input from list of hosts/networks
  -iR <num hosts>: Choose random targets
  --exclude <host1[,host2][,host3],...>: Exclude hosts/networks
HOST DISCOVERY:
  -sL: List Scan - simply list targets to scan
  -sP: Ping Scan - go no further than determining if host is online
  -P0: Treat all hosts as online -- skip host discovery
  -PS/PA/PU [portlist]: TCP SYN/ACK or UDP discovery probes
SCAN TECHNIQUES:
  -sS/sT/sA/sW/sM: TCP SYN/Connect()/ACK/Window/Maimon scans
  -sN/sF/sX: TCP Null, FIN, and Xmas scans
PORT SPECIFICATION AND SCAN ORDER:
  -p <port ranges>: Only scan specified ports
  -F: Fast - Scan only the ports listed in the nmap-services file
SERVICE/VERSION DETECTION:
  -sV: Probe open ports to determine service/version info
OS DETECTION:
  -O: Enable OS detection
TIMING AND PERFORMANCE:
  -T[0-6]: Set timing template (higher is faster)
OUTPUT:
  -oN/-oX/-oS/-oG <file>: Output scan results in normal, XML, s|Grepable format
MISC:
  -6: Enable IPv6 scanning
  -A: Enables OS detection and Version detection
  -V: Print version number
  -h: Print this help summary page.

Nmap Commonly Used Options

  • -sL (List Scan — lists the IPs of specified targets without performing host discovery)
  • -sn (Ping Scan — performs host discovery only, without port scanning)
  • -Pn (Treats all specified hosts as online, skipping host discovery)
  • -PS/PA/PU/PY (TCP SYN/ACK/UDP/SCTP discovery probes)
  • -PE/PP/PM (ICMP echo, timestamp, and netmask request discovery probes)
  • -n/-R (Never do DNS resolution / Always do DNS resolution)
  • --dns-servers (Specify custom DNS servers)
  • --traceroute (Perform a traceroute to each target)

Scanning Live Hosts

nmap -sn 10.1.1.1-100

Port Scanning Techniques

Nmap supports about a dozen different scanning techniques. Generally only one method is used at a time, except that UDP scanning (-sU) can be combined with any of the TCP scan types.

-sS (TCP SYN Scan)

SYN scan is the default and most popular scanning option. It is fast — on a fast network without intrusive firewalls, it can scan thousands of ports per second. SYN scan is relatively stealthy and hard to detect because it never completes a TCP connection.

-sT (TCP connect() Scan)

When SYN scan is not available, TCP connect() scan is the default TCP scan. This is the case when the user lacks privileges to send raw packets or is scanning IPv6 networks.

-sU (UDP Scan)

UDP scan is activated with the -sU option. It can be combined with a TCP scan such as SYN scan (-sS) to check both protocols simultaneously.

-sN; -sF; -sX (TCP Null, FIN, and Xmas Scans)

These three scan types exploit a subtle method in the TCP RFC to distinguish between open and closed ports.

Service and Version Detection

-sV (Version Detection) — Enables version detection. You can also use -A to enable both OS detection and version detection simultaneously.

OS Detection

-O (Enable OS Detection) — You can also use -A to enable both OS detection and version detection simultaneously.

Timing and Performance

-T[0-6] — Set timing template (higher is faster)

  • T0 (Paranoid) — For IDS evasion, extremely slow
  • T1 (Sneaky) — For IDS evasion, slow
  • T2 (Polite) — Slows down to use less bandwidth and target host resources
  • T3 (Normal) — Default mode
  • T4 (Aggressive) — Assumes the user has a suitable and reliable network, speeds up scanning
  • T5 (Insane) — Assumes the user has an exceptionally fast network or is willing to sacrifice accuracy for speed

Examples

nmap -v scanme.nmap.org
# Scans all reserved TCP ports on the host scanme.nmap.org. The -v option enables verbose mode.

nmap -sS -O scanme.nmap.org/24
# Performs a stealth SYN scan on the 255 hosts in the "Class C" subnet where scanme is located.
# Also attempts to determine the OS type of each live host.

nmap -sV -p 22,53,110,143,4564 198.116.0-255.1-127
# Performs host enumeration and TCP scan on 255 8-bit subnets in the Class B 188.116 network.

nmap -v -iR 100000 -P0 -p 80
# Randomly selects 100,000 hosts and scans whether they are running a web server (port 80).
