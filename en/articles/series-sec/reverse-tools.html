An organized overview of mainstream reverse engineering and decompilation tools, covering Java/.NET/Android/binary across multiple platforms.

General Reverse Engineering Tools

  • IDA — Multi-processor disassembler and debugger that works on Windows, Linux, or Mac OS X
  • OllyDbg — 32-bit assembly-level debugger for Windows
  • x64dbg — Open-source x64/x32 debugger for Windows
  • radare2 — Portable reverse engineering framework
  • Hopper — Disassembler/decompiler for 32/64-bit Windows/Mac/Linux/iOS executables on OS X and Linux
  • plasma — Interactive disassembler for x86/ARM/MIPS that generates pseudocode using obfuscation syntax analysis
  • ScratchABit — Easily retargetable and hackable interactive disassembler using an IDAPython-compatible plugin API

Java Decompilation

  • JAD — JAD Java decompiler (closed-source, infrequently updated)
  • JD-GUI — Standalone graphical utility that displays Java source code from ".class" files
  • procyon — Modern open-source Java decompiler
  • dex2jar — Tool for working with Android .dex and Java .class files
  • androguard — Reverse engineering and malware analysis tool for Android applications

.NET Decompilation

  • dotPeek — Free .NET decompiler developed by JetBrains
  • ILSpy — Open-source .NET assembly browser and decompiler
  • dnSpy — Tool for editing, decompiling, and debugging .NET programs
  • de4dot — Tool for cracking .NET programs
  • antinet — .NET tool for decompiling and obfuscating code
  • JustDecompile — .NET assembly decompiler and browser by Telerik

Other Tools

  • UPX — Ultimate executable packer
  • nudge4j — Java tool that lets the browser interact with the JVM
  • Malware Analysis Tutorial: Reverse Engineering — Comprehensive English-language tutorial
