I. Identity Authentication

1. /etc/login.defs
The /etc/login.defs file defines user restriction settings that work in conjunction with /etc/passwd and /etc/shadow. This file must exist; its absence will not prevent the system from running, but may cause unexpected errors.
If the same option exists in /etc/shadow, the /etc/shadow setting takes precedence — that is, /etc/shadow has a higher priority than /etc/login.defs.

2. /etc/passwd
username:pwd:UID(userID):GID(GroupID):comment:homepath:command namespace path
Using nologin disallows login.

3. /etc/shadow (root-only)
username:encrypted password:last change date:minimum change interval:password validity period:warning days before password change required:grace period after password expiry:account expiration date:reserved

IV. Resource Control (Prevent Ctrl+Alt+Del Reboot)

1. CentOS 7

cat /etc/inittab
vim /usr/lib/systemd/system/ctrl-alt-del.target
Comment out all lines
init q

2. CentOS 6

vim /etc/init/control-alt-delete.conf

V. Intrusion Prevention (Disable Unnecessary Services)

1. CentOS 7

systemctl list-unit-files | grep enable # List enabled services
systemctl disable nginx # Disable service

2. CentOS 6

chkconfig --list # List enabled services
chkconfig --level service 35 off # Disable service
