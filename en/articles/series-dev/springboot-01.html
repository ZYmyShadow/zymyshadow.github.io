Spring Boot Initial Framework Integration (Part 1)

Spring Boot Java Framework Integration Updated 2022-11-18 · Sect Master

藏
Integration contents: Spring Boot + spring-data-jpa + MySQL
Goal: Ready to use — just run a Maven build and it's ready to go. Includes database call examples, code templates for each layer, and annotations.

Create the Project

In your project, click File - New - Project in sequence.

If you just downloaded IDEA, click New Project.

After making all your selections, click Next, then choose your Spring Boot version.

Then click Create to create the project. Wait a moment and it will be ready.

Modify Configuration Files

There are two configuration files: pom.xml and application.properties

pom.xml: Maven package configuration file

application.properties: Project configuration file

Open the project configuration file and add the basic configuration:

# Project port configuration
server.port=8088

# Database driver
spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver
# URL
spring.datasource.url=jdbc:mysql://localhost:3306/springbootdemo
# Username
spring.datasource.username=root
# Password
spring.datasource.password=12345678
# Show query SQL
spring.jpa.show-sql=true
# Add hibernate.dialect
spring.jpa.database-platform=org.hibernate.dialect.MySQL5Dialect
# JPA working mode
# create: Recreates tables every time the program runs, causing data loss
# create-drop: Creates table structure when the program starts, drops tables when the program ends
# update: Creates tables if they don't exist; updates table structure if the entity changes; existing data is preserved (recommended)
# validate: Validates that data fields match the database; throws an error if fields differ
# none: Disables DDL processing
spring.jpa.hibernate.ddl-auto=update

Then Add Some Simple Code

  • Bean — Entity classes corresponding to database tables
  • Controller — API interfaces for frontend interaction
  • Repository — Single-table query operations, e.g., querying by a specific field, pagination, etc.
  • Service — All business logic; transforms data from the frontend into results through a series of operations

Bean Entity Class

@Entity(name = "test")
public class TestBean {
    @Id // Set primary key
    @GeneratedValue(strategy = GenerationType.IDENTITY) // MySQL auto-increment primary key mode
    private Long id; // Primary key, auto-increment
    @Column // Field annotation
    private String name; // Name
    @Column
    private Integer age; // Age
    @Column
    private String idCard; // ID card number
  // Getters and setters can be auto-generated by IDEA (required)
  // Override methods such as equals, toString, etc. can be auto-generated by IDEA (optional)
}

Controller Interface Layer

@RestController // Interface layer annotation
@RequestMapping(value = "/test")
public class TestController {

    private TestService testService;

    public TestController(TestService testService){
        this.testService = testService;
    }

    @GetMapping(value = "/hello") // GET interface annotation
    public String hello(@RequestParam(value = "name", defaultValue = "World") String name){
        return String.format("Hello %s", name);
    }

    @PostMapping(value = "/insertorupdate")
    public String insertOrUpdate(@RequestBody TestBean testBean){
        testService.insertOrUpdate(testBean);
        return String.format(testBean.toString());
    }

    @PostMapping(value = "/delete")
    public String delete(@RequestBody TestBean testBean){
        testService.delete(testBean);
        return String.format(testBean.toString());
    }

    @PostMapping(value = "/findbyid")
    public TestBean findByIdIs(@RequestParam Integer id){
        return testService.findByIdIs(id.longValue());
    }

    @PostMapping(value = "/findbyage")
    public List<TestBean> findByAge(@RequestParam Integer age){
        return testService.findByAge(age);
    }

    @PostMapping(value = "/findbyname")
    public List<TestBean> findByName(@RequestParam String name){
        return testService.findByName(name);
    }
}
