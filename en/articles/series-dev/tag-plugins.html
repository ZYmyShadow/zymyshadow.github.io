Tag Plugins Plus & Kmark Syntax

Hexo Butterfly Blog Updated 2022-08-30 · Sect Master

藏
This document provides complete usage documentation for tag plugins based on the Butterfly theme, covering syntax, parameters, and style previews for over 20 tags.

Inline Text Styles — text

{% u text content %}        Underlined text
{% emp text content %}       Text with emphasis dots
{% wavy text content %}      Wavy underlined text
{% del text content %}       Strikethrough text
{% kbd text content %}       Keyboard-style text
{% psw text content %}       Password-style text

Inline Text — span

{% span style parameters (space-separated), text content %}

Style parameters:
- Font: logo, code
- Color: red, yellow, green, cyan, blue, gray
- Size: small, h4, h3, h2, h1, large, huge, ultra
- Alignment: left, center, right

Blockquote — note

{% note [class] [no-icon] [style] %}
Any content (support inline tags too).
{% endnote %}

class: default / primary / success / info / warning / danger
style: simple / modern / flat / disabled

Superscript Tag — tip

{% tip [optional parameter] %}text content{% endtip %}

Styles: success, error, warning, bolt, ban, home, sync, cogs, key, bell
Custom icons: supports FontAwesome

Collapsible Box — folding

{% folding optional parameter, title %}
Content
{% endfolding %}

Color: blue, cyan, green, yellow, red
State: open means expanded by default

Checkbox List — checkbox

{% checkbox optional style parameter, text (supports simple markdown) %}

Style: plus, minus, times
Color: red, yellow, green, cyan, blue, gray
Checked state: checked

Radio List — radio

{% radio optional style parameter, text (supports simple markdown) %}

Color: red, yellow, green, cyan, blue, gray
Checked state: checked

Timeline — timeline

{% timeline optional title [,color] %}

Body content

{% endtimeline %}

color: default / blue / pink / red / purple / orange / green

Link Card — link

{% link title, link, optional image link %}

Buttons — btns

{% btns style parameters %}
{% cell title, link, image or icon %}
{% endbtns %}

Corner style: rounded, circle
Layout: wide, fill, center, around, grid2, grid3, grid4, grid5

GitHub Card — ghcard

{% ghcard username, optional parameters %}
{% ghcard username/repository, optional parameters %}

Common parameters:
- hide: stars,commits,prs,issues,contribs
- count_private: true
- show_icons: true
- theme: see Available Themes

Progress Bar — progress

{% progress [width] [color] [text] %}

width: number from 0 to 100
color: red, yellow, green, cyan, blue, gray
text: text displayed on the progress bar

Tabs — tab

{% tabs Unique name, [index] %}

Any content (support inline tags too).

{% endtabs %}

Unique name: unique name for the tab block
[index]: index of the active tab
[Tab caption]: current tab title
[@icon]: FontAwesome icon name

Poem Tag — poem

{% poem [title],[author] %}
Poem content
{% endpoem %}

Effect Tag — wow

{% wow [animate],[duration],[delay],[offset],[iteration] %}
Content
{% endwow %}

animate: animation style, see animate.css documentation for effects
duration: animation duration, can be in ms or s
delay: animation start delay time
offset: distance from bottom of browser viewport to trigger animation
iteration: number of animation repetitions
