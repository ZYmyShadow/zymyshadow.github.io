PS:从哪些方面进行加固？

  • 身份鉴别
  • 访问控制
  • 安全审计
  • 资源控制
  • 入侵防范

一、身份鉴别

1. /etc/login.defs
/etc/login.defs文件定义了与/etc/passwd和/etc/shadow配套的用户限制设置。这个文件是一定要存在的，缺失并不会影响系统的使用，但是也许会产生意想不到的错误。
如果/etc/shadow文件里面相同的选项，则以/etc/shadow里面的设置为准，也就是说/etc/shadow的配置优先级高于/etc/login.defs。

2. /etc/passwd
username:pwd:UID(userID):GID(GroupID):注释:homepath:command namespace path
如果使用nologin是不允许登录

3. /etc/shadow(root专属)
username:加密密码:最后一次修改时间:最小修改时间间隔:密码有效期:密码需要变更前的警告天数:密码过期后的宽限天数:账号失效时间:保留

二、访问控制

1. /etc/ssh/sshd_config(ssh功能配置)

配置项说明
Port 22端口
ListenAddress 0.0.0.0监听地址，只能使用这个地址访问，配置内网地址
LoginGraceTime 2m连接主机时输入密码的时间超过多长时间就断开
PermitRootLogin yes是否允许root登陆
MaxAuthTries 6可以测试密码的次数
MaxSessions 3同时发起登陆请求的数量
ClientAliveCountMax 3客户端超时次数

2. /etc/bashrc — 修改权限 一般是 022 027 077

3. /etc/profile

4. /etc/hosts.deny — 主机黑名单 - sshd:ALL

5. /etc/hosts.allow — 主机白名单 - sshd:10.0.0.248

三、安全审计

1. /etc/rsyslog.conf
写法：
*.err;kern.debug;deamon.notice /var/log/adm.log
*.* @192.168.0.1:514

四、资源控制（防止快捷键重启）

1. centos7

cat /etc/inittab
vim /usr/lib/systemd/system/ctrl-alt-del.target
全注释掉
init q

2. centos6

vim /etc/init/control-alt-delete.conf

五、入侵防范（关闭不必要的服务）

1. centos7

systemctl list-unit-files | grep enable #查看开启的服务
systemctl disable nginx #关闭服务

2. centos6

chkconfig -list #查看开启的服务
chkconfig --level service 35 off #关闭服务
