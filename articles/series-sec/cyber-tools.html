网络安全工具

工具集 渗透测试 更新于 2022-09-15 · 宗主

网安
本文整理数十款经典网络安全工具的功能定位与使用场景，覆盖漏洞扫描、嗅探、渗透、密码破解等领域。

漏洞扫描工具

  • Nessus — 最好的免费网络漏洞扫描器，可运行于几乎所有的UNIX平台之上，免费提供多达11000种插件
  • OpenVAS — Nessus的开源分支，功能强大的漏洞扫描器
  • GFI LANguard — Windows平台上的商业网络安全扫描器，可发现运行中的计算机并收集操作系统版本和应用程序信息
  • Retina — eEye出品的商业漏洞评估扫描器
  • SAINT — 象Nessus、ISS Internet Scanner和Retina一样的商业漏洞评估工具
  • QualysGuard — 基于网页的漏洞扫描器，含有5000种以上的单一漏洞检查
  • Acunetix WVS — 商业网页漏洞扫描器，自动检查SQL注入、跨网站脚本等漏洞
  • Nikto — 非常全面的网页扫描器，包含超过3200种有潜在危险的文件/CGIs
  • WebInspect — 强大的网页程序扫描器，帮您识别已知和未知的网页层漏洞

网络嗅探与分析

  • Wireshark — 非常棒的Unix和Windows上的开源网络协议分析器，可以实时检测网络通讯数据
  • Tcpdump — 最经典的网络监控和数据捕获嗅探器，漏洞非常少，消耗系统资源也非常少
  • Kismet — 一款超强的无线嗅探器，基于命令行的802.11 layer2无线网络探测器
  • NetStumbler — 免费的Windows 802.11嗅探器，广为人知的寻找开放无线访问接入点的工具
  • Ntop — 网络通讯监控器，以类似进程管理器的方式显示网络使用情况

渗透测试框架

  • Metasploit Framework — 强大的开源平台，供开发、测试和使用恶意代码，自带上百种漏洞
  • Core Impact — 全自动的全面入侵检测工具，有一个强大的定时更新的专业漏洞数据库
  • Canvas — Aitel's ImmunitySec出品的漏洞检测工具，包含150个以上的漏洞

密码破解工具

  • John the Ripper — 最快的密码破解器，当前支持多种主流Unix、DOS、Win32、BeOS和OpenVMS
  • Cain and Abel — Windows平台上最好的密码恢复工具，可以通过嗅探网络来找到密码
  • THC Hydra — 支持多种服务的最快的网络认证破解器，可以同时对30个以上的端口进行基于字典的快速破解
  • RainbowCrack — 极具创新性的密码哈希破解器，使用了大规模内存时间交换技术
  • Aircrack — 最快的WEP/WPA破解工具，是一套用于破解802.11a/b/g WEP和WPA的工具套装

端口扫描与主机发现

  • Nmap — 网络探索和安全审计的开源工具，支持主机发现、端口扫描、服务版本探测、操作系统检测
  • Masscan — 最快的互联网端口扫描器，能在6分钟内扫描整个互联网
  • Angry IP Scanner — 一款非常快的Windows IP扫描器和端口扫描器
  • Superscan — 只运行于Windows平台之上的端口扫描器、ping工具和解析器

防火墙与IDS/IPS

  • Netfilter — 最新的Linux核心数据包过滤器/防火墙，集成了用户空间IP列表工具
  • Openbsd PF — OpenBSD数据包过滤器，被OpenBSD用户最爱用的防火墙工具
  • Snort — 一款广受欢迎的开源IDS（入侵检测系统）工具，擅长于通讯分析和IP数据包登录
  • OSSEC HIDS — 一款开源的基于主机的入侵检测系统，主要功能有日志分析、完整性检查、rootkit检测

逆向工程与调试

  • IDA Pro — Windows或Linux反编译器和调试器，遵守二进制包事实标准的恶意代码和漏洞研究分析工具
  • OllyDbg — 汇编级Windows调试器，因其直接对二进制代码进行分析，所以在无法获得源代码的时候非常有用
  • radare2 — 便携式的逆向工程框架工具

加密与匿名

  • GnuPG / PGP — 对您的文件和通讯进行高级加密，GnuPG是一款口碑很好的遵守PGP标准的开源应用
  • Tor — 匿名网络通讯系统，功能有匿名网页浏览和发布、即时信息、irc、ssh等
  • OpenSSL — 最好的SSL/TLS加密库，开发一种健壮的、可以和同类型商业程序媲美的全功能的开源加密库工具集
  • TrueCrypt — 开源的Windows和Linux磁盘加密软件，用户可以加密整个文件系统

其他实用工具

  • Netcat — 网络瑞士军刀，可以读和写经过TCP或UDP网络连接的数据
  • Hping2 — 一种网络探测工具，是ping的超级变种，可以发送自定义的ICMP，UDP和TCP数据包
  • Sysinternals — 一款强大的非常全面的Windows工具合集，包含ProcessExplorer、PsTools、Autoruns等
  • VMware — 多平台虚拟软件，允许您在一个系统中虚拟运行另一个系统，对于安全专家在多平台下测试代码和漏洞非常有用
  • BackTrack — 一款极具创新突破的Live光盘自启动Linux系统平台，以其超级多的安全和防护工具配以丰富的开发环境而闻名
  • Perl / Python / Ruby — 简单的、多用途的脚本语言，常用的安全问题都能在网上找到工具解决，但使用脚本语言您可以编写您自己的工具
