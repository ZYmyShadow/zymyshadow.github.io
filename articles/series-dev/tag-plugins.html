本文档为基于Butterfly的外挂标签引入完整使用文档，涵盖20余种标签的语法、参数与样式预览。

行内文本样式 text

{% u 文本内容 %}        带下划线的文本
{% emp 文本内容 %}       带着重号的文本
{% wavy 文本内容 %}      带波浪线的文本
{% del 文本内容 %}       带删除线的文本
{% kbd 文本内容 %}       键盘样式的文本
{% psw 文本内容 %}       密码样式的文本

行内文本 span

{% span 样式参数(参数以空格划分), 文本内容 %}

样式参数:
- 字体: logo, code
- 颜色: red, yellow, green, cyan, blue, gray
- 大小: small, h4, h3, h2, h1, large, huge, ultra
- 对齐方向: left, center, right

引用 note

{% note [class] [no-icon] [style] %}
Any content (support inline tags too).
{% endnote %}

class: default / primary / success / info / warning / danger
style: simple / modern / flat / disabled

上标标签 tip

{% tip [参数，可选] %}文本内容{% endtip %}

样式: success, error, warning, bolt, ban, home, sync, cogs, key, bell
自定义图标: 支持fontawesome

折叠框 folding

{% folding 参数（可选）, 标题 %}
内容
{% endfolding %}

颜色: blue, cyan, green, yellow, red
状态: open 代表默认打开

复选列表 checkbox

{% checkbox 样式参数（可选）, 文本（支持简单md） %}

样式: plus, minus, times
颜色: red, yellow, green, cyan, blue, gray
选中状态: checked

单选列表 radio

{% radio 样式参数（可选）, 文本（支持简单md） %}

颜色: red, yellow, green, cyan, blue, gray
选中状态: checked

时间轴 timeline

{% timeline 时间线标题（可选）[,color] %}

正文内容

{% endtimeline %}

color: default / blue / pink / red / purple / orange / green

链接卡片 link

{% link 标题, 链接, 图片链接（可选） %}

按钮 btns

{% btns 样式参数 %}
{% cell 标题, 链接, 图片或者图标 %}
{% endbtns %}

圆角样式: rounded, circle
布局方式: wide, fill, center, around, grid2, grid3, grid4, grid5

github卡片 ghcard

{% ghcard 用户名, 其它参数（可选） %}
{% ghcard 用户名/仓库, 其它参数（可选） %}

常用参数:
- hide: stars,commits,prs,issues,contribs
- count_private: true
- show_icons: true
- theme: 请查阅Available Themes

进度条 progress

{% progress [width] [color] [text] %}

width: 0到100的阿拉伯数字
color: red, yellow, green, cyan, blue, gray
text: 进度条上的文字内容

分栏 tab

{% tabs Unique name, [index] %}

Any content (support inline tags too).

{% endtabs %}

Unique name: 选项卡块标签的唯一名称
[index]: 活动选项卡的索引号
[Tab caption]: 当前选项卡的标题
[@icon]: FontAwesome图标名称

诗词标签 poem

{% poem [title],[author] %}
诗词内容
{% endpoem %}

特效标签 wow

{% wow [animete],[duration],[delay],[offset],[iteration] %}
内容
{% endwow %}

animate: 动画样式，效果详见animate.css参考文档
duration: 动画持续时间，单位可以是ms也可以是s
delay: 动画开始的延迟时间
offset: 开始动画的距离（相对浏览器底部）
iteration: 动画重复的次数
