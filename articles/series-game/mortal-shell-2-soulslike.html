Mortal Shell II定档8月20日：独立类魂游戏的生存突围

MortalShell2 类魂游戏 独立游戏产业 ColdSymmetry 游戏定价策略 更新于 2026-08-14 · 宗主 · 约 14 分钟

躯壳

一、引言：Steam商店页面弹出的一条发售日通知

8月中旬的一个深夜，宗主我照例在Steam愿望单里翻翻拣拣，一条发售日通知跳了出来：《Mortal Shell II》定档2026年8月20日，标准版49.99美元，Devout版59.99美元，购买Devout版可于8月17日提前72小时入库（来源：Steam商店官方页面、Steam新闻公告）。

宗主的记忆一下子被拉回2020年。那年8月，初代《Mortal Shell》在Epic独家发售，售价29.99美元。宗主当时花了一个周末通关，印象最深的是"硬化"机制：按一个键，角色变成石头，硬扛敌人一击，然后反击。这个机制简单粗暴，但在类魂游戏里算是一个有辨识度的设计。初代的体量不大，四个Shell、四把武器，通关时间大约十来个小时，是一款典型的"小团队做硬核品类"的产品（来源：Metacritic、GamingBolt）。

六年过去，Cold Symmetry这个当初只有十几人的小团队，带着一款体量翻倍、价格也涨了将近七成的续作回来了。Steam商店页面的描述写着："Their Flesh Is Your Weapon. Mortal Shell II is a standalone sequel action-RPG with adrenaline-charged, high-stakes combat. Possess warrior Shells, dethrone false gods, redeem a ravaged world."（来源：Steam商店官方页面）。"standalone sequel"（独立续作）这个词很关键：不需要玩过初代，直接上手二代没问题。

但宗主用技术脑多想了一层：从30美元到49.99美元，这不只是通胀调整，而是品类定位的切换。30美元是"小品级独立游戏"的安全区，玩家对体量和打磨度的容忍度较高；49.99美元已经踩到了中等体量3A的门槛线。一个独立团队在这个价位拿出什么水准的产品，才能让玩家觉得"值"？

核心观点
Mortal Shell II的定档，表面是一款独立续作终于面世，深层逻辑是独立类魂游戏在FromSoftware 3A化魂系时代的生存突围：要么往上走，用更大的体量和更高的价格争夺核心受众的注意力和钱包；要么留在原地，被3A魂系和休闲肉鸽两头挤压。Cold Symmetry选择了往上走，但这条路的风险也最大。

二、从30美元到49.99美元：Mortal Shell系列六年的产品跃迁

先把两代产品的关键参数放在一起比一比，看看Cold Symmetry这六年到底做了多少事。

初代《Mortal Shell》2020年8月18日发售，开发商Cold Symmetry，发行商Playstack（来源：Metacritic）。Metacritic媒体评分方面，PC版76分，Xbox One版75分，PS4版也在75分上下（来源：Metacritic各平台页面）。注意，这里需要纠正一个常见说法：部分中文媒体将初代Metacritic评分概括为"约70分"，实际各平台媒体综合评分在75至76分之间，属于"Generally Favorable"（总体好评）区间。初代的核心特色是"硬化"机制：角色可以瞬间石化，免疫一次攻击，然后反击。武器只有四把近战武器加一把远程弩，Shell（可附身的战士躯壳）只有四个，游戏体量紧凑，通关大约十到十五小时（来源：GamingBolt、Metacritic）。

初代的问题也很明显。GamingBolt在对比文章中指出，初代的武器种类太少，耐力条导致战斗节奏重复："移动到攻击位置、砍两刀、退回等耐力恢复、再重复"（来源：GamingBolt）。宗主个人体感：初代的环境美术有辨识度，但区域之间重复感较强，后期探索的动力不足。不过，硬化机制作为核心防守工具确实得到了社区好评，被认为是在资源有限条件下做出的有创意的设计（来源：Metacritic媒体评价、ResetEra社区讨论）。

再看二代。Steam商店页面和GamingBolt的详细对比文章披露了以下变化（来源：Steam商店页面、GamingBolt）：

Shell数量从4个增加到9个，每个Shell有独立的技能树。武器从4把近战+1把远程扩展到8把主武器+8把副武器（含火器）。世界从线性互联区域改为"紧凑开放世界"（compact open world），加入地图、快速旅行、攀爬和钩爪等探索机制。地下城数量超过80个（Steam商店页面写的是"more than 80 dungeons"）。战斗系统彻底重做：移除耐力条，引入姿态破坏系统（posture-breaking）、颜色编码的攻击预警（红色不可格挡、黄色可弹反）、以及将硬化机制进化为模块化的"封印"（Seals）系统。

还有一个有意思的新武器：吟游诗人的鲁特琴（Troubadour's Lute），用音乐旋律来解除敌人武装，算是一种偏"和平主义"的战斗选项（来源：GamingBolt）。这大概就是此前资料里提到的"弦乐器音波攻击"。

内容量翻倍，团队规模也在扩张。据finalboss.io报道，Mortal Shell II的开发团队约30人（来源：finalboss.io）。相比初代十几人的规模，团队几乎翻倍，但放在游戏行业里依然是典型的小团队。30人做出80多个地下城、9个Shell、16种武器和一套开放世界系统，这个产能密度是相当激进的。

价格的跃迁就在这个背景下发生。初代30美元，二代标准版49.99美元、Devout版59.99美元（来源：Steam商店页面、Steam新闻公告、AltChar）。涨幅接近67%。Devout版额外提供72小时提前入库权限和部分外观内容。Steam国区定价198元人民币（来源：中关村在线援引Steam数据）。

实例
宗主翻了一下自己2020年买初代时的订单记录：Epic独占期间花了约117港币（当时约合15美元），后来上了Steam又补了一份。说实话，初代30美元的价格对那种体量来说是合理的：短而聚焦，有辨识度，但不追求规模。现在二代直接跳到49.99美元，宗主的第一反应不是"太贵了"，而是"它得给出和这个价格匹配的内容深度和打磨度"。80个地下城、9个Shell听起来量够了，但量不等于质，初代就证明了"小而美"和"小而糙"之间只有一线之隔。

三、独立类魂的生存夹缝：3A化魂系时代的中间地带

Mortal Shell II的定价跃迁，是整个独立类魂品类生存困境的一个侧面。

要理解这个困境，得先看类魂品类的格局变化。2022年《艾尔登法环》发售，FromSoftware把魂系游戏从"线性关卡+高难度战斗"推向了"开放世界+自由探索"的3A化方向。这款游戏全球销量超过2500万份（来源：FromSoftware官方财报，宗主个人记忆，具体数值建议以官方最新公布为准），拿下了2022年TGA年度最佳游戏。此后，《艾尔登法环》的DLC《黄金树幽影》在2024年继续收割核心受众注意力和钱包。据多方报道，FromSoftware还在推进《艾尔登法环》的多人衍生作品和可能的新作（来源：多家游戏媒体报道，具体项目状态以官方公告为准）。

FromSoftware的3A化路线，实际上抬高了类魂品类的准入门槛。当玩家可以用60美元买到一个内容量数百小时、制作精良的开放世界魂系3A时，为什么要花50美元买一个独立团队的"紧凑开放世界"类魂？

这就是独立类魂游戏面临的"上方挤压"。而"下方挤压"同样不容忽视。近年来，以Roguelite机制为核心的"轻量类魂"或"类魂肉鸽"产品大量涌现，价格通常在15到25美元区间，用随机性和重复可玩性弥补单次通关深度的不足。这些产品学习曲线更平缓，单局时间更短，对碎片化时代的玩家更友好。

独立类魂游戏被夹在中间：往上，拼不过3A魂系的制作规模和品牌号召力；往下，拼不过肉鸽品类的价格优势和重复可玩性。Mortal Shell II的49.99美元定价，恰好卡在这个"上下夹击"的中间地带。这个价位既不像30美元那样可以让玩家"闭眼入"当作尝鲜，又不像60美元3A那样有品牌背书支撑购买决策。玩家在掏钱之前会多问一句：它凭什么值这个价？

Cold Symmetry的回答似乎是"内容量翻倍+品类进化"。从参数上看，80个地下城、9个Shell、16种武器，这个内容量确实比初代上了一个台阶，甚至不逊于一些中等体量的3A产品。但参数不等于体验：80个地下城如果设计同质化，反而会成为扣分项；9个Shell如果差异度不够，也只是数字好看。

宗主注意到一个细节：Mortal Shell II在2026年夏季游戏节期间办过一场公开BETA测试（来源：Steam商店页面，页面显示有"Download Mortal Shell II - Open Beta"入口）。开放公测对于独立游戏来说是一个聪明的策略：既收集了真实玩家反馈来调优，又在发售前制造了一波口碑传播。GamingBolt的对比文章提到，BETA测试玩家反馈称新的"封印"系统"极大地改变了他们的防守策略"（来源：GamingBolt），说明至少核心战斗系统的改版是经过实战验证的。但公测版和正式版之间还有多少差距，只能等8月20日见分晓。

核心观点
独立类魂游戏的生存空间正在被3A魂系和轻量肉鸽两头压缩。Mortal Shell II选择用49.99美元的定价和翻倍的内容量往上突围，本质上是赌"核心类魂受众愿意为深度和品质支付接近3A的价格"。这个赌注能否赢，取决于产品打磨度能否支撑价格预期，而非参数列表是否够长。

四、移除体力条：品类进化的豪赌还是核心用户的疏远

在Mortal Shell II所有改动中，最具争议性的一定是移除体力条。

体力条是类魂游戏的"教条"之一。从《恶魔之魂》到《黑暗之魂》再到《血源诅咒》，耐力管理一直是FromSoftware魂系战斗的核心资源约束：你的每一次攻击、闪避、格挡都要消耗耐力，耐力耗尽就只能被动挨打。这个机制迫使玩家在战斗中不断做资源管理决策：是贪一刀还是安全撤退？是连续攻击压制还是留耐力准备闪避？体力条的存在，让魂系战斗不是纯粹的"反应力测试"，而是"资源管理+反应力"的复合博弈。

Mortal Shell II把这个机制整个砍掉了。Steam商店页面明确写道："Unrestricted by stamina, players exploit multiple tactics to shatter enemy posture and strike critically."（不受耐力限制，玩家运用多种战术击破敌人姿态并发动致命一击）（来源：Steam商店页面）。GamingBolt的详细对比文章确认："Stamina Bar Removed - One of Mortal Shell 1's biggest grievances has been completely removed for the sequel"（耐力条移除：初代最大的grievances之一在续作中被完全移除）（来源：GamingBolt）。GamesHorizon的文章也指出："The Stamina bar is completely removed this time around. Attacking, dodging, and blocking won't drain any resources anymore."（来源：GamesHorizon）。

这个改动的影响，比表面看起来大得多。根据GamingBolt的分析，移除体力条后，战斗节奏从"攻防交替的资源博弈"变成了"连续进攻的压迫式战斗"。Shell的技能不再受耐力约束，而是在攻击中自动充能，鼓励玩家持续保持进攻态势。同时，游戏引入了姿态破坏系统来替代体力条的资源约束功能：连续攻击可以打崩敌人姿态，创造致命一击的窗口（来源：GamingBolt）。

国内的什么值得买上有玩家分析文章指出，移除耐力条后战斗"反而更窒息了"，不是因为节奏变慢，而是因为它快得让你不敢喘气。前作那种"算着体力打"的保守博弈被取代，取而代之的是连招零消耗、闪避无惩罚的"永动"机制，但代价是闪避无敌帧缩短、格挡容错率下降，空刀一次就可能被敌人一套反杀（来源：什么值得买玩家分析文章，属玩家社区观点）。

宗主认为，这个改动本质上是Mortal Shell II在做一次品类定位的切换：从"传统类魂"向"高速动作游戏"靠拢。GamingBolt的文章也持类似观点，认为移除体力条使续作的战斗风格"更接近现代动作冒险游戏（modern action-adventure titles），而非动作RPG"（来源：GamingBolt）。

这是一步险棋。

险在哪里？第一，类魂游戏的核心受众之所以选择这个品类，很大程度上就是冲着"资源管理+高惩罚"的战斗博弈来的。体力条是这个博弈框架的基石。移除它，等于抽掉了传统类魂玩家最熟悉的节奏感。如果新玩家觉得"没有体力条=不够硬核"，这个标签反而会劝退一批被"类魂"吸引来的用户。

第二，姿态破坏系统能否完全替代体力条的资源约束功能，是一个未知数。体力条约束的不只是攻击频率，还包括战斗的整体节奏感：什么时候该进攻、什么时候该退守，这个决策框架是体力条塑造的。姿态破坏系统提供了"连续攻击打崩敌人"的正向激励，但能否提供同等的"什么时候该收手"的负向约束，需要实际体验才能判断。

第三，Mortal Shell II同时做了开放世界化和移除体力条两个大改动。开放世界意味着探索自由度增加，但类魂游戏的关卡设计精髓在于"精心编排的线性路径中藏岔路"，初代和FromSoftware的《黑暗之魂》都是这个路数。开放世界化之后，探索的密度和战斗的节奏感能否保持，本身就是挑战。再加上战斗系统的彻底重做，两个大改动叠加，风险成倍增加。

但机遇也在。如果Cold Symmetry能把"无体力条+姿态破坏+模块化封印"这套新战斗系统打磨到位，Mortal Shell II有可能走出一条不同于FromSoftware的路线：不是"慢节奏资源博弈"，而是"快节奏连续压制"。在FromSoftware自己都在往开放世界3A方向走的当下，独立类魂游戏如果继续模仿FromSoftware的旧配方，只会被3A的正统续作碾压。差异化进化，反而是更合理的生存策略。

实例
宗主自己玩初代Mortal Shell的时候，最矛盾的感受就是：硬化机制很有创意，但体力条的存在让战斗节奏显得拖沓，尤其是打一些血厚的精英怪时，"砍两刀-退回等体力-再砍两刀"的循环重复感很强。当时宗主就想：如果能把体力条砍掉，让战斗更流畅，同时用别的机制来约束玩家的进攻节奏，会不会更好？现在二代真的这么做了，宗主既期待又担心。期待的是"流畅类魂"的体验，担心的是失去了体力条的约束后，战斗深度是否会下降。这种矛盾感，大概也是很多初代玩家的共同心态。

五、结语：50美元这个门槛，独立游戏要跨过去需要什么

写到这里，宗主想把三条线收一收。

Mortal Shell系列六年，从30美元的小品级硬核游戏，走到了49.99美元的中等体量独立续作。内容量翻倍，世界开放化，战斗系统推倒重来。Cold Symmetry这个约30人的团队，在用规模和野心赌一个更大的未来。

但独立类魂游戏的生存空间确实在收窄。FromSoftware的3A化魂系把品类的制作标准抬到了一个独立团队难以企及的高度，轻量肉鸽则在低价位段分流了潜在受众。49.99美元这个定价，意味着Mortal Shell II不再能躲在"便宜所以容忍瑕疵"的庇护伞下，它必须和接近3A价位的产品正面对比，用品质说话。

移除体力条是Cold Symmetry做出的最大胆的决定。这个改动有可能成为Mortal Shell II的标志性特色，让它从"FromSoftware的模仿者"变成"有自己的战斗语言"的独立作品；也有可能疏远那些被"类魂"标签吸引来的核心用户，让他们觉得"这不是我想要的类魂"。

对玩家来说，宗主的建议是：如果你玩过初代并且喜欢硬化机制的创意，Mortal Shell II值得关注，但建议等8月20日正式发售后看看首发评价再决定。Devout版的72小时提前入库（8月17日开始）看起来诱人，但提前三天进入一个尚未经过大规模玩家验证的新战斗系统，风险不小。如果你没玩过初代也不用担心，官方明确说了这是standalone sequel，不需要前作基础（来源：Steam商店页面）。

对行业来说，Mortal Shell II的表现将成为独立类魂游戏能否在50美元价位站住脚的一个重要参考。如果它成功了，会鼓励更多独立团队在硬核品类里追求更大的体量和更高的定价；如果它表现平平，可能意味着独立类魂的天花板依然卡在30美元的"小品级"区间。

宗主寄语
独立游戏做硬核品类，最怕的不是做不到3A的规模，而是用3A的价格做出了独立游戏的瑕疵。Mortal Shell II移除体力条的那一刻，就已经选择了不走寻常路，这条路走下去，要么成为品类的新定义者，要么成为"过度野心"的反面教材。8月20日，答案揭晓。

至于宗主自己，8月20日那天打算先看看Steam首发评价，如果战斗系统的改版确实做出了差异化，再入手不迟。毕竟，50美元不是30美元，多等两天不丢人。
