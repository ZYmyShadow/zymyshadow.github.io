模组简介

拔刀剑 (SlashBlade) 是一款在 Minecraft 中加入日式刀剑（KATANA）与连击攻击系统的模组。以下是来自 CurseForge 官方页面的模组描述原文：

Welcome to SlashBlade. This is a MOD created to add the DMC-ish KATANA in the game. Enjoy the combo attack! This Mod is a fan work of Demon Blade, DMC & PSO2

该模组是 《魔剑》（Demon Blade）、《鬼泣》（DMC）和《梦幻之星在线2》（PSO2） 的同人作品，旨在为 Minecraft 带来类似动作游戏的刀剑战斗体验，核心特色是连击攻击系统。

开发者信息

拔刀剑模组在 CurseForge 上的注册作者为 flammpfeil，也是该模组的原始日本作者。模组源代码托管在 GitHub 上，仓库地址为 flammpfeil/SlashBlade。

核心特性

  • 日式刀剑——在游戏中加入各种日式刀剑（KATANA），具有独特的攻击动作与效果
  • 连击攻击系统——核心玩法是 combo attack 连击攻击，提供类似动作游戏的战斗体验
  • 同人创作——模组灵感来源于《魔剑》《鬼泣》《梦幻之星在线2》等作品，是这些 IP 的同人衍生作品
