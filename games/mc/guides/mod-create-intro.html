模组简介

机械动力 (Create) 是一款提供建造、装饰与美学自动化（Aesthetic Automation）工具和方块的 Minecraft 模组。以下是来自 CurseForge 官方页面的模组描述原文：

Welcome to Create, a mod offering a variety of tools and blocks for Building, Decoration and Aesthetic Automation. The added elements of tech are designed to leave as many design choices to the player as possible. With Create, the game isn't played inside a bunch of UIs, it challenges you to setup contraptions of animated components working together in many possible arrangements. Create's visual in-game documentation called 'Ponder' will guide you though all added mechanics and gadgets.

简而言之，机械动力的核心设计理念是：不依赖大量 UI 界面，而是通过组装动画组件来构建各种机械装置，让玩家在可视化、沉浸式的体验中实现自动化生产。

开发者信息

机械动力的主要开发者（Owner）为 simibubi。开发团队成员包括 Jozufozu、Pepper、Zelophed、gamez7、Grimmauld、Snownee 等。模组源代码托管在 GitHub 上，由 Creators-of-Create 组织维护。

核心特性

  • 美学自动化——模组添加的科技元素旨在将尽可能多的设计选择权留给玩家，强调自动化的视觉效果与美学表现
  • 动画组件系统——玩家需要设置由动画组件组成的机械装置（contraptions），让各部件协同工作，而非在 UI 界面中操作
  • Ponder 可视化文档——模组内置名为「Ponder」的游戏内可视化文档系统，会引导玩家了解所有添加的机制与工具
  • 建造与装饰——除了自动化功能外，模组还提供建筑和装饰相关的工具与方块
